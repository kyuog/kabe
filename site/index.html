Así se ve Kabe

La imagen manda: miniatura grande, cero adorno. La paleta —índigo, neblina y un solo ámbar— se respeta en toda la interfaz, y el tema del sistema decide si es clara u oscura.

Instálalo en un minuto

Disponible como .deb, AppImage y Flatpak.

# Debian, Ubuntu, MX Linux sudo apt install ./kabe_0.1.0_amd64.deb # Cualquier distribución sudo ./install.sh # Versión portable (sin instalar) tar xf kabe-0.1.0-x86_64-portable.tar.gz && ./AppDir/AppRun
Descargar .deb Portable install.sh

Dependencias: python3 y python3-gi con gir1.2-gtk-3.0, que ya vienen en XFCE, GNOME, Cinnamon, MATE, LXQt y KDE.
